# linosklad-stock

Публичный JSON остатков для витрины **linosklad.ru**. Репо **открытый специально**: сайт читает без логина. Код витрины — private `s200586-art/linosklad`.

`stock-live.json` — погонные метры по Тюмени из письма 1С «остатки по всем складам для бота». Карточки, фото и цены живут на сайте, не здесь.

Последнее: смотри `asOf` в JSON (на 17.09.2026 — 64 дизайна / 164 sku).

`parse.py` — разбор Excel.
